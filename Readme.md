# Projekt NoSQL

## Wybór projektu:
3.6 Cache dla aplikacji e-commerce

## Opis projektu:
Aplikacja pozwala na przeglądanie sklepu online oraz dodawanie produktów do prywatnego koszyka.

## Funkcjonalności:
- Przeglądanie przedmiotów w sklepie
- Dodawanie przedmiorów do koszyka
- Przeglądanie koszyka
- Usuwanie obiektów w koszyku
- Wyczyszczenie koszyka
- Zatwierdzenie koszyka - "zakup"

## Technologie i rozwiązania:
- **Redis** - dane w koszyku użytkownika
- **Node.js + Express.js** - backend aplikacji
- **Pug Templates** - frontent aplikacji
